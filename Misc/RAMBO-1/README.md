# RAMBO-1

 * Manufacturer: NCR
 * Type: Standard cell
 * Die markings: X1347171 146X148
 * Die picture: https://siliconprawn.org/map/tengen/rambo-1/furrtek_mz/
 * Function: Bankswitching and security
 * Used in: Tengen NES games
 * Chip donator: krzysiobal

# Pinout

* Unbonded pin between 39 and 40 would be PRG_A18
* Unbonded pins between 14 and 15, and between 28 and 29 are related to PPU A11 and the register at $A000 bit 1
* Pin 19 is a test enable for the CIC function, test data is output on the CPU data pins. See schematics MISC page
